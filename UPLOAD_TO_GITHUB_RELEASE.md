# Upload ConnectNow.exe to GitHub Releases

## Steps:

1. **Go to GitHub Releases:**
   https://github.com/aointel/AOIrail/releases

2. **Create New Release:**
   - Click "Draft a new release"
   - Tag version: `v1.0.3`
   - Release title: `ConnectNow Desktop App v1.0.3`
   - Description:
     ```
     # ConnectNow Desktop App v1.0.3
     
     ## ✅ Features:
     - Automatic HPPRO presentation tracking
     - Screenshot capture every 30 seconds
     - Page scraping every 10 seconds
     - Live Board integration
     - No installation required - portable app
     
     ## 📥 Download:
     Click "ConnectNow.exe" below to download (158 MB)
     
     ## 🚀 Usage:
     1. Download ConnectNow.exe
     2. Run it (no installation needed)
     3. Log in with your credentials
     4. Open HPPRO - tracking starts automatically!
     ```

3. **Upload File:**
   - Drag and drop: `C:\Users\mmand\OneDrive\Desktop\AOI\electron-dist\AO Intelligence 1.0.3.exe`
   - Rename it to: `ConnectNow.exe` in the assets section

4. **Publish Release:**
   - Click "Publish release"

5. **Verify Download Link:**
   After publishing, the download link will be:
   `https://github.com/aointel/AOIrail/releases/download/v1.0.3/ConnectNow.exe`

That's it! The app is already configured to use this URL.
