# 📢 Announcement Changelog - Ready for User Display

## Version 2025.01.15 - Call Connector Pro Updates & Improvements

### 🎯 **Call Connector Pro Access Changes**
- **Stricter Access Control**: Only agents with **active** Stripe subscriptions now have access to Call Connector Pro

- **Stripe Billing Portal**: Manage all subscriptions, change payment methods, update billing info, and view history from the billing dashboard
- **Unified Credit Purchase**: All "Buy Credits" buttons now link to the same billing dashboard

### 📊 **Call Metrics Improvements**
- **Fixed Dial Counting**: Resolved double-counting issue - dial numbers are now accurate
- **Accurate Totals**: Statistics totals now reflect ALL agents, not just the current page
- **Instant Presentations**: Now correctly tracked and displayed

### 🤖 **Answering Machine Detection**
- **AMD Enabled**: Outbound calls now detect if answered by human or machine
- **Data Available**: AMD results stored in call logs for analysis

### 🔔 **User Experience**
- **Reduced Notifications**: Fixed annoying toast notifications after calls
- **Better Navigation**: Consistent links throughout the app
